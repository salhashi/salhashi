# Sentinel

Sentinel is an in-progress intrusion detection project with the Western Cyber Society. It turns predictions about network activity into alerts that an analyst can review.

## My role

I’m leading development of the model-serving API and the real-time security dashboard. The API serves network-flow classifications and confidence scores. The dashboard surfaces detections and helps analysts prioritize which alerts to investigate.

We plan to validate the system against replayed traffic and live honeypot data.

**Stack** · Python, FastAPI, React, TypeScript
